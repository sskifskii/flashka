# SPEC-0008: Одностороннее создание карточки

Date: 2026-10-16

## Цель и границы

Уместить создание карточки в доступную область мобильного экрана с открытой
клавиатурой. Меняется только frontend формы создания; модель карточки, API и
обязательность обеих сторон остаются прежними.

## Правила и инварианты

- При открытии формы видна только сторона `Front`.
- Действие «Развернуть» переключает `Front` и `Back` сколько угодно раз, не
  теряя введённый текст, и переводит фокус в поле показанной стороны.
- Переключение выглядит как быстрый пространственный разворот карточки на 180°;
  длительность задаётся одной CSS-переменной и учитывает `prefers-reduced-motion`.
- Визуальные подписи сторон компактны и вторичны относительно введённого текста.
- На мобильном вся форма занимает только верхнюю область, сопоставимую с
  пространством над открытой клавиатурой; при закрытой клавиатуре нижняя часть
  экрана остаётся свободным фоном, а не растягивает форму.
- «Сохранить» доступно на обеих сторонах. При ошибке в одной из сторон форма
  показывает эту сторону и сообщение рядом с её полем.
- Редактирование существующей карточки сохраняет одновременный доступ к обеим
  сторонам; их подписи используют те же `Front` и `Back`.

## Критерии приёмки

1. Новая карточка открывается на `Front`, а `Back` отсутствует из видимой формы.
2. После нескольких разворотов введённые значения обеих сторон сохраняются.
3. Валидные `front` и `back` отправляются существующим запросом создания с любой
   активной стороны.
4. На мобильном шапка, выбор папки и одна компактная сторона одновременно
   помещаются над клавиатурой без прокрутки между `Front` и `Back`.
5. Component-тест проверяет переключение, сохранность ввода и валидацию скрытой
   стороны.
