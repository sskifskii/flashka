# Feature-specs

В этой папке хранятся нумерованные спецификации крупных вертикальных срезов.
Общие правила и критерии необходимости описаны в
[DEVELOPMENT.md](../DEVELOPMENT.md).

- [SPEC-0008: Одностороннее создание карточки](0008-single-side-card-editor.md)

Workflow-статусы ведутся только в [ROADMAP.md](../ROADMAP.md). При создании spec
сюда добавляется одна ссылка; при смене статуса этот файл не обновляется.

## Шаблон

```markdown
# SPEC-NNNN: Название функции

Date: YYYY-MM-DD

## Цель и границы

## Правила и инварианты

## Критерии приёмки

1. ...

## Блокирующие вопросы
```

Обычно spec занимает не более 60 строк. Неприменимые разделы удаляются. Полные
API-схемы, устройство реализации, общий Definition of Done и подробный план
тестов не повторяются. После самостоятельной проверки агент сразу меняет статус
среза в roadmap на `In progress` и начинает реализацию.
